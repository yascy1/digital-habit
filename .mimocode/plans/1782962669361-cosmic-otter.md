# Fix: Icon pencil kosong di modal detail riwayat

## File
`app/riwayat/page.tsx`

## Masalah
`IconPencil` dihapus dari import (baris 5-22) dan dari tombol edit (baris 1046-1050), sehingga tombol edit tampil kosong tanpa icon.

## Perubahan

### 1. Tambah kembali `IconPencil` ke import (baris 13, setelah `IconPlus`)
```ts
IconPencil,
```

### 2. Kembalikan `IconPencil` ke tombol edit (baris 1049, di dalam `<button>` yang kosong)
```tsx
<IconPencil className="size-3.5" />
```

## Verifikasi
- Build `npm run build` tanpa error
- Buka halaman riwayat → klik lihat detail → tombol edit harus tampilkan icon pencil
