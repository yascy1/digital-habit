# Fix: Warning hapus aktivitas terakhir — tampilan lebih mencolok

## Masalah
Warning "tidak akan mereset" vs "akan mereset" terlalu mirip — user tidak akan ngeh bedanya.

## Fix
**File:** `app/riwayat/page.tsx`

### 1. Import icon peringatan
Tambah `IconAlertTriangle` di import `@tabler/icons-react` (baris 5-25).

### 2. Ubah judul dialog
Saat `isLastActivityToday`:
- Judul: **"Hapus aktivitas terakhir?"**
- Bukan: "Yakin ingin menghapus?"

### 3. Tambah icon + warna merah
Saat `isLastActivityToday`:
- Tampilkan `IconAlertTriangle` dengan warna oranye/merah di depan teks
- Teks "Tindakan ini akan mereset streak kamu." pakai warna merah (`text-red-500 font-bold`)

### Kode yang diubah

Import icon:
```tsx
import { IconAlertTriangle, ... } from "@tabler/icons-react"
```

Judul dialog:
```tsx
<AlertDialogTitle className="font-bold">
  {isLastActivityToday ? "Hapus aktivitas terakhir?" : "Yakin ingin menghapus?"}
</AlertDialogTitle>
```

Deskripsi:
```tsx
<AlertDialogDescription className={`font-medium ${isLastActivityToday ? "text-red-500" : "text-slate-500"}`}>
  {isLastActivityToday && <IconAlertTriangle className="inline size-4 mr-1" />}
  Aktivitas ini akan dihapus permanen.{" "}
  {isLastActivityToday
    ? "Tindakan ini akan mereset streak kamu."
    : "Tindakan ini tidak akan mereset streak kamu."}
</AlertDialogDescription>
```

## File yang diubah
- `app/riwayat/page.tsx` — import icon + judul + deskripsi dinamis

## Verifikasi
1. Hapus aktivitas biasa → judul "Yakin ingin menghapus?", teks abu-abu
2. Hapus aktivitas terakhir hari ini → judul "Hapus aktivitas terakhir?", teks merah + icon peringatan
