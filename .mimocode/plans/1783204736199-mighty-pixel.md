# Plan: Fix Insight Section — Dynamic Text per Filter

## Masalah
Section insight di dashboard selalu menampilkan teks "Insight Hari Ini" dan deskripsi "hari ini" meskipun filter Mingguan/Bulanan aktif.

## Penyebab
1. **Header hardcoded** di baris 607: `<h2>Insight Hari Ini</h2>` — tidak berubah mengikuti filter
2. **Deskripsi** di `computeInsights` (baris 320): teks `period === "Harian" ? "hari ini" : \`dalam ${period.toLowerCase()}\`` menghasilkan "dalam mingguan" / "dalam bulanan" — grammatically awkward

## Fix: `app/dashboard/page.tsx`

### 1. Header dinamis (baris 605-608)
```typescript
// SEBELUM:
<h2 className="font-heading text-lg font-extrabold tracking-tight text-slate-900">
  Insight Hari Ini
</h2>

// SESUDAH:
const insightLabel = activeFilter === "Harian" ? "Hari Ini" : activeFilter === "Mingguan" ? "7 Hari Terakhir" : "30 Hari Terakhir"
// ...
<h2 className="font-heading text-lg font-extrabold tracking-tight text-slate-900">
  Insight {insightLabel}
</h2>
```

### 2. Deskripsi di `computeInsights` (baris 320)
```typescript
// SEBELUM:
description: `${topCat[0]} menyumbang ${topPercent}% total waktu layarmu ${period === "Harian" ? "hari ini" : `dalam ${period.toLowerCase()}`}.`

// SESUDAH:
const periodText = period === "Harian" ? "hari ini" : period === "Mingguan" ? "dalam 7 hari terakhir" : "dalam 30 hari terakhir"
description: `${topCat[0]} menyumbang ${topPercent}% total waktu layarmu ${periodText}.`
```
